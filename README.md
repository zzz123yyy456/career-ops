* Simple To-Do application that stores tasks in the browser's localStorage.
* Open index.html in a browser to use.

Features
- Add tasks
- Mark complete / toggle
- Edit (double click)
- Delete tasks
- Clear completed / Clear all
- Persistent storage via localStorage

How to run
1. Clone the repo or download the files.
2. Open index.html in your browser.

Future ideas
- Drag to reorder
- Due dates / reminders
- Tags / filtering
- Sync between devices
